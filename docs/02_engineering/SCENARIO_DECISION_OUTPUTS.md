# 场景化 Company Scorecard 与 Action Plan 契约

## 1. 基本原则

行业研究是所有商业场景共用的证据底座，但 Company Scorecard 与 Action Plan 必须服务于具体决策，不能把一套企业能力评分机械复制到所有场景。

- 场景包通过 `decision_output_policy` 声明评分单元、维度、收敛规则、行动字段和反馈闭环。
- 公共研究内核、证据可追溯、人工审核、版本历史和反馈回写属于受保护不变量。
- 后续战略分析 Skill 只能通过 `strategy_skill_slot` 覆盖指定方法节点，不得绕过受保护不变量。
- PE 本阶段保持现有 IC Memo、价值创造计划和投后反馈设计，不做方法改写。

## 2. 企业增长决策

### 两条增长曲线

1. 第一增长曲线：从核心产品出发，研究产品与应用场景的交叉覆盖、买家采购门槛、单位经济性及30天客户验证，服务近期订单、毛利和现金流。
2. 第二增长曲线：从核心能力出发，研究高增长下游、应用适配、能力补齐和进入路线，服务未来3—5年增长。

研究形成5条候选机会长名单，收敛至不超过3条战略优先级，最终只为1—2条机会生成 Action Plan。

### Company Scorecard

评分单元是 `growth_opportunity`，不是抽象的公司总分。必需维度包括：

- 增长机会与市场窗口；
- 产品与应用场景适配；
- 买家采购与采用门槛；
- 单位经济性与盈利质量；
- 进入路径与渠道可达性；
- 组织资源与执行能力；
- 资源与能力缺口；
- 风险、验证成本与可逆性。

每个维度同时展示企业当前能力、可比市场平均和实现战略目标所需的能力门槛。

### Action Plan

每项行动必须包含责任人、时序、资源、依赖、客户验证任务、领先指标、结果指标、风险、停止或转向条件和反馈频率。反馈闭环为：客户接触 → 样品/测试 → 报价/试单 → 渠道/成交 → 更新机会评分与行动优先级。

## 3. VC 投资分析

VC 的评分单元是 `investment_hypothesis`。维度包括市场时点、创始团队、技术壁垒、产品市场证据、商业模式、里程碑可实现性、融资与 Runway、下行风险。

Scorecard 比较当前证据、基金投资门槛和下一里程碑门槛，形成推进、观察或暂不推进判断。进入 DD 后，将未证实的投资假设转成有负责人、所需证据、里程碑、Runway 影响、跟投触发和停止/退出条件的 Milestone Plan。

投后反馈必须联动创始人反馈、客户验证、里程碑证据和融资变化，并写回基金—标的知识空间。

## 4. Skill 扩展接口

当前预留两个策略方法插槽：

- `growth_strategy_method`：机会评分、战略优先级、能力匹配、行动排序；
- `vc_investment_method`：投资假设、里程碑设计、基金适配评分、跟投逻辑。

Skill 包必须声明版本、输入输出结构、适用场景和方法边界。加载新 Skill 后生成新版本，不静默改写已经批准的 Scorecard 或 Action Plan。
