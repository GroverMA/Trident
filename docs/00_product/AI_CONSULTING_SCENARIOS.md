# AI 咨询分析：场景化主动诊断架构

## 产品入口原则

- 左侧一级导航承载 Trident Agent 的完整能力，不再直接堆叠历史项目。
- Agent 导航在首页、行业研究、企业决策、项目工作台、报告和运营监测中持续存在；项目导航作为行业研究内部的第二层上下文导航。
- 一级能力包括 AI 咨询分析、企业增长决策、行业研究、PE/VC 投资、新闻与信号、企业画像、历史决策分析、项目管理、运营监测和研究知识库。
- `AI 咨询分析` 是默认入口；`项目管理` 独立承载研究项目与历史档案。
- 四个场景共享行业定义、市场规模、竞争格局、驱动因素、证据审阅与报告标准。
- 通用行业研究完整保留现有审阅式与构建式流程；PE、VC、企业增长战略是在同一研究内核之上增加不同的访谈、判断和行动输出。

## 共同前置流程

1. 用户选择决策场景。
2. 用户只需给出目标与少量已知条件。
3. AI 根据前一轮回答主动选择下一问题，而不是展示固定长表单。
4. 用户可以输入文字、使用语音转文字，或上传已有材料；缺少数据不阻断流程。
5. 系统形成决策目标契约、用户/企业画像、决策风格和待验证假设。
6. 画像与假设转化为后续研究任务，进入对应专业研究流。

## 四个场景

### 通用行业研究

保留现有构建式与审阅式双流程：Prompt Analysis → Gate 0 → Web Research → Gate 1 → Industry Analysis → Future Intelligence → Gate 2 → General Report。

### PE 投资分析

投资人决策风格 → 标的经营质量与现金流诊断 → 行业位置与竞争研究 → 财务/商业/管理层 DD → 估值与价值创造计划 → IC Memo → 投后监测。

### VC 机会发现

投资人决策风格 → 项目快照与初筛 → 技术/商业/团队/资本四维 DD → 风险收益与回报情景 → IC Memo → 投后关键里程碑监测。

### 企业增长战略

第二增长曲线或生存型增长目标 → 访谈与资料合并输入 → 企业画像与增长问题树 → 定向市场机会与下游应用研究 → 5 条机会地图 → Company Scorecard 收敛至最多 3 条战略路径 → Action Plan → KPI 动态复盘。

企业增长场景不输出通用行业报告。行业研究只覆盖增长目标需要的客户需求、下游应用、市场吸引力、竞争进入条件和关键风险。下游应用筛选保留版本化 Skill 接口，等待专业方法包接入。

## 数据完整度分层

- 高数字化企业：直接接收销售、订单、财务、物流、渠道与产品数据。
- 部分数字化企业：接收表格、扫描件、业务系统导出和管理层材料。
- 低数字化企业：允许管理层口述；内容先标记为待验证判断，后续逐步补数。

资料缺失影响结论置信度与验证任务，不应成为进入下一阶段的无理由阻断条件。

## 当前试验版与后续实现边界

当前版本验证入口信息架构、目标校准、四轮主动访谈、可选材料入口、企业画像和研究流预览。下一阶段需要接入模型驱动的问题路由、语音识别服务、文件解析与项目级持久化，并为 PE、VC 和企业增长分别建立状态机、输出结构和验收标准。
