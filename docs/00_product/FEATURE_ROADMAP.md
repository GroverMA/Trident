# Feature Roadmap

## Roadmap Principles

- 先保证研究闭环与可靠性，再扩展场景和企业连接。
- 通用能力采用成熟工具；差异化集中在 Trident Skill、证据质量与决策逻辑。
- 模型、搜索、数据库和云平台均通过适配层替换。
- 规划能力必须与当前能力分开标注。
- 所有里程碑默认同时交付 Vercel 海外版与腾讯云大陆版；“区域部署”只改变承载方式，
  不改变研究流程和功能范围。

## Now：融资 Demo 与双区域可访问版本

### Milestone N1：统一 Web 工作台

- **状态**：进行中。
- Next.js 前端 + FastAPI 后端。
- 保留构建式、审阅式及企业战略流程。
- Streamlit 作为兼容/历史演示版本，不再作为未来主 Web 架构。

### Milestone N2：完整研究闭环

- **状态**：核心服务已存在，持续做端到端稳定性验证。
- Prompt→范围→搜索→证据→行业分析→趋势→报告。
- 企业资料→Scorecard→Action Plan→Enterprise Report。
- 模块级审阅和版本保留。

### Milestone N3：双区域部署

- **状态**：海外可访问；中国容器已运行，公网入口待修复。
- 海外版本继续托管部署。
- 中国大陆 Demo 使用腾讯云 CloudBase 默认域名。
- 同一代码库，以环境变量区分。
- 中国 Demo 可显式使用持久化 SQLite 单实例；有可写 PostgreSQL 后切换。

### Milestone N4：基础质量与安全

- 结构化输出归一化、未知引用过滤、报告内部 ID 清理。
- 关键工作流自动测试。
- 凭证只通过环境变量，历史暴露凭证需要轮换。

### Release Criteria

- 两种研究方式各完成至少一次通用和企业端到端测试。
- 关键六模块非空；Word/PDF 成功导出。
- 局部修订不覆盖其他模块。
- CloudBase 和海外版本均能公开访问。
- 同一提交、同一领域/API/Skill 版本和同一核心回归集同时用于两个区域；任何只在单一区域
  通过的变更只能标记为“区域部署验证中”，不能标记为已完成。

## Next：可对客标准 SaaS

### Milestone S1：多租户与权限

- PostgreSQL 多租户模型、RLS、RBAC、审计和备份。
- 用户、组织、项目、资料和报告版本权限。

### Milestone S2：异步长任务

- 早期使用 Celery + Redis；规模化后评估 Temporal。
- 分布式 Worker、任务重试、幂等、取消、进度、死信与成本记录。

### Milestone S3：长期记忆与持续感知

- 企业画像、管理者决策风格、项目判断、行动和反馈的时间化记忆。
- 新闻、政策、竞争者、客户与内部指标订阅。
- 新信号触发重新分析和计划调整。

### Milestone S4：场景包

- PE/VC：赛道、标的、尽调、投委会、投后监测。
- 中小企业增长：市场需要、政策影响、经营策略、组织与行动建议。
- Scenario Pack Registry 与版本管理。

### Milestone S5：商业化能力

- 组织管理、用量、套餐、成本治理、客户支持和服务交付入口。
- “软件订阅 + 研究额度 + 专家服务/定制 Skill”的组合收费。

## Later：企业级决策基础设施

### Milestone E1：企业连接

- 标准 API 和增量同步。
- SAP、CRM、数据仓库、SharePoint/对象存储连接器。
- 数据语义层、映射规则和血缘。

### Milestone E2：企业部署与合规

- 私有云/VPC/Kubernetes、企业 API 网关。
- SSO、KMS、SIEM、数据驻留、密钥轮换与高可用。

### Milestone E3：高级算法与仿真

- 可插拔预测、因果推断、仿真、优化和评分策略。
- Benchmark & Case Library 与企业知识图谱。
- 策略离线评估、在线监控和灰度发布。

## Dependencies

| 能力 | 前置依赖 |
|---|---|
| 多租户 SaaS | PostgreSQL、认证、组织模型、RLS、审计 |
| 分布式长任务 | Redis/队列、对象存储、幂等任务模型 |
| 持续感知 | 来源授权、调度器、去重、事件模型、通知 |
| 企业连接 | 数据映射、权限委托、连接器 SDK、血缘 |
| 高级算法 | 结构化训练/评估数据、指标、实验治理 |

## Risks

- 把 Demo 的 SQLite 或单 Worker 当成生产架构。
- 场景扩展过快，稀释通用研究质量。
- 依赖单一模型或搜索供应商。
- 企业资料安全、数据驻留和授权边界不清。
- 评分基准缺少足够案例校准，给出虚假精确度。
