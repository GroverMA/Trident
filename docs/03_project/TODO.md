# 项目待办与优先级

## 当前阶段目标

把已经验证的 Trident 研究能力迁移为可公开演示、可持续迭代的 Web Agent，同时不修改原 Industry Analyst 仓库。当前版本首先保证通用研究与企业战略研究在构建式、审阅式两种路径下都能完成端到端运行。

## 完成定义

- 四条主路径均可从新建项目运行至报告生成与下载。
- 任务中断后可恢复，历史项目可继续、存档或删除。
- 报告、证据、判断、评分和行动建议可追溯且不会泄露内部编码。
- 海外与中国大陆 Demo 使用同一代码库、不同部署配置。
- 两个区域使用同一研究流程、功能、领域/API/Skill 版本和核心测试集；所有迁移与新增
  功能同步部署、同步验收。
- 敏感凭证不进入仓库、日志或前端。
