# 发布规划

## 发布等级

| 发布等级 | 目标用户 | 数据与部署 | 关键能力 | 支持边界 |
|---|---|---|---|---|
| Demo | 投资人、设计伙伴、受控试用者 | 托管云；可使用显式 SQLite 演示配置 | 核心研究流程、报告展示、有限项目保存 | 非 SLA；不得上传真实机密；数据可能不持久 |
| SaaS Beta | 中小企业、研究团队、PE/VC 小团队 | PostgreSQL、多租户、对象存储、异步 Worker | 长期记忆、持续感知、场景包、权限和成本治理 | 标准支持；明确配额和数据保留规则 |
| Enterprise | 大型企业与受监管机构 | 私有云/VPC/K8s、企业数据库和系统连接 | SSO、审计、KMS、连接器、私有 Skill、知识图谱 | 企业 SLA、实施服务、灾备与合规交付 |

## 当前版本：0.3.0

定位为架构迁移与双区域 Demo 基线。适合验证产品流程和基础设施，不代表已经满足正式企业生产要求。

## 计划版本：0.4.0

- 完成异步 Job 与进度恢复。
- 完成四条主流程回归测试。
- 稳定 PostgreSQL 数据模型与迁移。
- 增加模块化报告修订和版本对比。
- 完成 CloudBase 健康检查、日志和数据持久化验证。

## 目标版本：1.0

- 多租户 SaaS 基线。
- 长期记忆和持续感知。
- 通用研究、企业增长和 PE/VC 场景包。
- 三线动态 Scorecard 与可执行 Action Plan。
- 模型、搜索、Skill 和成本可观测性。
- Word/PDF/网页报告的一致导出质量。

## 企业版本：2.x

- 企业 API 网关、SSO、RBAC/RLS、KMS 与 SIEM。
- SAP、CRM、数据仓库和内部知识库连接。
- 私有化部署、企业知识图谱和专属 Benchmark Library。
- 高可用调度、灾备、审计和服务等级保障。

## 发布检查清单

- [ ] 同一提交和版本已部署至 Vercel 海外版与腾讯云大陆版；不存在区域业务代码分叉。
- [ ] 两个区域使用相同领域/API/数据契约、Skill/Prompt 与核心回归测试版本。
- [ ] 两个区域的构建、健康/就绪检查及受影响端到端路径均有验收记录；未通过项明确
      标记为部分部署，未宣称发布完成。
- [ ] 所有数据库迁移可正向执行并有回滚或恢复方案。
- [ ] 四条端到端路径通过。
- [ ] 未提交凭证、客户数据和生成报告样本中的敏感信息。
- [ ] 依赖、镜像和公开端点完成安全检查。
- [ ] 版本号、变更日志、部署说明和已知问题已更新。
- [ ] Word、PDF 和网页报告经过视觉抽检。
